## 📌 Core Concepts & Patterns

- Expand right, shrink left while condition breaks
- Longest / shortest valid subarray or substring
- Hashmap / frequency array for window state
- At-most-K trick: exactly(K) = atMost(K) - atMost(K-1)
- Min window substring pattern
